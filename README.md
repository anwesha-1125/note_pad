
📝 **NotePad App**

A lightweight NotePad application built using Node.js, Express.js, EJS, and the File System (FS) module. This project allows users to manage notes by creating, viewing, editing, renaming, and deleting text files through a clean web interface.

✨**Features**
📝 Create new notes

📖 View note contents

✏️ Edit note title and content

🗑️ Delete notes

📂 Stores notes as .txt files using Node.js File System

🎨 Responsive UI built with Tailwind CSS

⚡ Fast and lightweight


🛠️ **Tech Stack**

Node.js

Express.js

EJS

HTML5

Tailwind CSS

JavaScript

File System (fs) Module
